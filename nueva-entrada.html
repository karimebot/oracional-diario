Nueva entrada

Esta página no publica nada por sí sola: prepara los datos y las fotos para que tú los subas a GitHub.

Cómo publicar (3 pasos)

  1. Llena el formulario y presiona Generar entradas.json. Si agregas fotos, descarga también las fotos listas.
  2. En GitHub, sube las fotos a la carpeta fotos (Add file → Upload files).
  3. Abre entradas.json en GitHub (ícono del lápiz), selecciona todo, pega el contenido nuevo y presiona Commit changes. En 1 o 2 minutos aparece en el historial.

Datos de la entrada

Las fotos se reducen a un tamaño liviano (máx. 1200 px) para que el sitio cargue rápido. Descárgalas con el nombre que se muestra y súbelas a la carpeta fotos.
